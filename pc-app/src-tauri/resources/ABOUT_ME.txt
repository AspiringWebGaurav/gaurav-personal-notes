WHY GAURAV PERSONAL NOTES?
--------------------------------------------------------------------------------
I built Gaurav Personal Notes because I wanted a notes app that:
- Starts up in milliseconds without heavy memory usage
- Always works 100% offline so your thoughts are never blocked by internet
- Stores your data locally on your computer with complete privacy
- Seamlessly syncs to the cloud when you are connected
- Keeps interfaces clean with simple words and zero unnecessary jargon

TECH STACK
--------------------------------------------------------------------------------
* Windows Desktop : Rust + Tauri v2 (Fast native speed, tiny RAM footprint)
* Web Application : Next.js, React, TypeScript, Tailwind CSS
* Local Storage   : Native SQLite on Windows
* Cloud Sync      : Firebase Firestore + GPHost CDN Storage
