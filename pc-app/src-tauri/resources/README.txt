                       GAURAV PERSONAL NOTES (GPN)
                   Fast, Private & Offline Notes App
================================================================================

Welcome to Gaurav Personal Notes!

Gaurav Personal Notes is a fast, clean, and reliable notes app for Windows 10
and Windows 11. It is built to give you a distraction-free space to capture
your thoughts, daily plans, code snippets, and ideas with instant speed.


KEY FEATURES
--------------------------------------------------------------------------------
* Instant Speed: Opens and saves notes immediately with local storage.
* Works Offline: Write and search notes without an active internet connection.
* Cloud Sync: Notes automatically sync whenever you are online.
* Quick Capture: Press Ctrl + Shift + N anywhere in Windows to jot down ideas.
* Instant Search: Press Ctrl + K to search through all notes instantly.
* Windows Dark & Light Mode: Matches your Windows personalization theme.
* Media Uploads: Attach screenshots, images, and files via GPHost CDN.


KEYBOARD SHORTCUTS
--------------------------------------------------------------------------------
Ctrl + N          : Create a new note
Ctrl + K          : Search all notes (Command Palette)
Ctrl + Shift + N  : Quick Capture scratchpad from anywhere
Ctrl + S          : Save / Sync current note
Ctrl + Shift + B  : Smart Burn (self-destructing secret note)
Ctrl + /          : View all shortcuts


WHERE ARE YOUR NOTES STORED?
--------------------------------------------------------------------------------
Your notes are safely stored locally on your Windows PC at:
%LOCALAPPDATA%\com.gpn.desktop\

You always have 100% control and privacy over your own notes.


HOW TO UNINSTALL
--------------------------------------------------------------------------------
If you ever wish to remove this application:
1. Double-click "uninstall.exe" in this folder.
   OR
2. Open Windows Settings -> Apps -> Installed Apps -> Gaurav Personal Notes
   -> Click "Uninstall".
   OR
3. Open the app, go to the "Permissions" tab, and click "Uninstall App".
